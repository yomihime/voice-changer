# Voice Recorder

朗読音声とテキストを収集・書き出す、上流由来の録音ツールです。本 fork では保守対象外とし、ソースを履歴資料として残しています。VCClient のリアルタイム音声変換には使用しません。

ビルド出力と開発サーバーの配信先は、このディレクトリ内の `dist/` です。ルートの `docs/` は製品ドキュメント用とし、Recorder の clean・build からは変更しません。旧コピーコマンドは削除しました。

以前 `docs/` にあった公開ページは、ライセンスと素材を含めて [legacy-site/](legacy-site/) に移動しました。ビルド・再配布はしていません。録音はブラウザの保存領域に属するため、ソースや公開ファイルの移動ではユーザーの録音データは移行されません。

依存関係・録音動作・旧バックエンド起動コマンドの動作は保証していません。
